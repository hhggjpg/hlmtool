## 一、基础篇（看懂 `examples/hello_api.py` 就够了）

### 1. 程序与文件

| 概念 | 一句话解释 | 本项目例子 |
|---|---|---|
| ⭐ 脚本 / 程序 | 一个 `.py` 文件就是一份"说明书"，从第一行往下逐行执行 | `hello_api.py` |
| ⭐ 注释 `#` | 从 `#` 到行尾全是给人看的，Python 完全无视 | 每行末尾的中文 |
| ⭐ 执行顺序 | 从上往下一行一行跑；**放到后面的赋值，前面用不了** | 第 5 行必须在第 8 行之前 |
| 🔸 空白行 | 不影响运行，只为分段好看 | 第 4、6、11、19 行 |

### 2. 引入工具

| 概念 | 一句话解释 | 本项目例子 |
|---|---|---|
| ⭐ 模块（module） | 一个"工具箱"，里面装着一堆现成的工具 | `os`、`dotenv` |
| ⭐ 包（package） | 装模块的箱子 | `openai` |
| ⭐ `import 箱子` | 把整个工具箱搬来，用时必须带名字：`os.getenv(...)` | 第 1 行 |
| ⭐ `from 箱子 import 零件` | 只掏一个零件出来，用时直接喊名字 | 第 2、3 行 |
| ⭐ 内置 vs 第三方 | 内置的（`os`、`print`、`len`）开箱即有；第三方的（`openai`、`dotenv`）必须先 `pip install` | `requirements.txt` 里那几行 |
| ⭐ 大小写敏感 | `openai`（包）和 `OpenAI`（类）是两个毫不相干的名字。写错会 `ImportError`，Python 有时还会提示 `Did you mean: 'OpenAI'?` | 第 2 行 |

### 3. 值与变量

| 概念 | 一句话解释 | 本项目例子 |
|---|---|---|
| ⭐ 字面量（literal） | 直接写在代码里的现成值 | `"deepseek-flash"`、`1` |
| ⭐ 变量 | 给某个值贴的名字标签 | `client`、`response` |
| ⭐ `=`（赋值） | 把右边算出来的东西，贴个名字存起来。**不是"等于"** | 第 7、12 行 |
| ⭐ `==`（判断相等） | 比较两边是不是一样，结果是 `True`/`False`。本项目暂时没用到 | 与 `=` 完全不同 |
| ⭐ 名字查找规则 | 不加引号的名字，Python 从近到远找：函数内 → 文件里 → Python 自带。**找不到就 `NameError`** | 忘了 `import os` 就会报这个 |
| ⭐ 引号的作用 | 加引号 = 这串文字本身；不加引号 = 让 Python 去找一个叫这个名字的东西 | `os.getenv("DEEPSEEK_API_KEY")` |
| ⭐ `None` | Python 表示"什么都没有"的特殊值。**取不到东西时常常安静地给你 `None`，不报错** | 第 5 行删掉后第 8 行会拿到 `None` |
| 🔹 类型 | 值的种类：字符串 `str`、整数 `int`、小数 `float`、真假 `bool`、空 `NoneType` | `"abc"` / `123` / `1.5` / `True` |

### 4. 函数与调用

| 概念 | 一句话解释 | 本项目例子 |
|---|---|---|
| ⭐ 函数（function） | 可以被"喊一声就干活"的工具 | `load_dotenv`、`len`、`print` |
| ⭐ `()` 调用 | **括号 = 动手执行**。不写括号只是"把工具指给你看"，什么都不会发生 | `load_dotenv` vs `load_dotenv()` |
| ⭐ 参数（argument） | 括号里递进去的"材料" | `os.getenv("DEEPSEEK_API_KEY")` 里的那串文字 |
| ⭐ 位置参数 | 靠**排队顺序**决定是哪个材料：`load_dotenv("keys.txt")` | 只有一份材料时常用 |
| ⭐ 关键字参数 | 靠**名字**决定：`api_key=...`、`base_url=...`。**顺序可以调换** | 第 8、9 行 |
| ⭐ 返回值（return value） | 干完活交回来的结果。有返回值的可以存进变量 | `len(...)` 有；`print(...)` 没有 |
| ⭐ `print` vs 有返回值的函数 | `print` 是喇叭，只往屏幕上喊，交回 `None`；`len` 是把结果递到你手里 | `x = print("hi")` → `x` 是 `None` |
| ⭐ `print` 多参数 | 逗号隔开，挨个打印，**中间自动加一个空格**。比用 `+` 拼接安全 | 第 20–23 行 |

### 5. 容器：列表与字典

| 概念 | 一句话解释 | 本项目例子 |
|---|---|---|
| ⭐ 列表 `[ ]` | 一排**有先后顺序**的格子，靠**位置**取值 | `messages`、`response.choices` |
| ⭐ 字典 `{ }` | 一堆"**键: 值**"配对，靠**键名**取值，**没有顺序** | `{"role": "system", "content": "..."}` |
| ⭐ 键的数量 | **不固定**，你写几对就是几对（0 对、1 对、100 对都行） | 本项目每条消息是 **2** 对 |
| ⭐ 键不能重名 | 同一个字典里键写重了，**后写的静默覆盖前面的**，不报错 | 做人物表时容易踩 |
| ⭐ `:` 在字典里 | 读作"**这个键对应这个值**"——往盒子里塞一对 | `"role": "system"` |
| ⭐ `,` 逗号 | "下一项"。在函数括号里、列表里、字典里都是这个意思 | 到处都是 |
| ⭐ 索引 `[0]` | 取**第零个**（=人说的第一个）。**Python 从 0 开始数** | `response.choices[0]` |
| ⭐ 嵌套 | 列表里装字典、字典里装列表，可以层层套 | `messages` 是列表，里面每项是字典 |
| ⭐ 取值方式对照 | **方括号 = 查表**（列表靠位置、字典靠键名）；**点号 = 进包裹**（对象） | 见下面"对象"一节 |

### 6. 类与对象（本项目最重要的一组概念）

| 概念 | 一句话解释 | 本项目例子 |
|---|---|---|
| ⭐ 类（class） | 一张"模具/职位的定义"，本身不能干活。**约定首字母大写** | `OpenAI`、`CompletionUsage` |
| ⭐ 对象 / 实例 | 按模具造出来的**具体那一个**。造出来的动作就叫"实例化" | `client`、`response` |
| ⭐ 实例化 | 类名后面加括号：`OpenAI(...)` = 按这张模具造一个出来 | 第 7–10 行 |
| ⭐ 属性（attribute） | 对象身上挂的数据，用**点号**取 | `response.usage`、`response.choices` |
| ⭐ 方法（method） | 长在对象身上的函数。**加括号才执行** | `client.chat.completions.create(...)` |
| ⭐ 多层点号 | 一层层往里走，像文件路径。**最右边那个才可能是动作** | `client.chat.completions.create` |
| ⭐ 对象长什么样 | 直接 `print` 一个对象，会显示它的"自我介绍"，**那串文字不是数据，是给人看的说明** | `CompletionUsage(completion_tokens=48, ...)` |

### 7. 环境变量与密钥安全

| 概念 | 一句话解释 | 本项目例子 |
|---|---|---|
| ⭐ 环境变量 | 操作系统给每个程序准备的一小块"公共便签墙"，名字自取，值是文字，**程序结束就消失** | `DEEPSEEK_API_KEY` |
| ⭐ `.env` 文件 | 一张"草稿纸"，一行一个 `名字=值`。**只存活在磁盘上，方便你放便签** | 项目根目录 |
| ⭐ `load_dotenv()` | 把 `.env` 的内容**抄到便签墙上**。不写括号 = 什么都不发生 | 第 5 行 |
| ⭐ `os.getenv("名字")` | 从便签墙上按名字取货。**给的是"标签文字"，不是值本身** | 第 8 行 |
| ⭐ 为什么密钥不能写进代码 | 代码要传 GitHub，**全世界都能看到**；密钥放 `.env`，用 `.gitignore` 排除 | `.gitignore` |
| ⭐ `.gitignore` | 一个清单，告诉 git "这些文件不要上传"。**它是安全清单，不是密钥** | 项目根目录 |

## 三、最容易混的几组（验收高频）

| 容易混 | 区别 |
|---|---|
| `=` 和 `==` | `=` 是**贴名字**（赋值）；`==` 是**问"一样吗"**（比较，返回 True/False） |
| `print` 和 `return` | `print` 往屏幕**喊**，交回 `None`；`return` 把结果**交回**给调用它的地方 |
| 加了括号和没加括号 | 加括号 = **动手执行**；没加 = 只是把工具指给你看 |
| 位置参数和关键字参数 | 位置参数靠**顺序**；关键字参数靠**名字**（顺序可调换） |
| 列表和字典 | 列表靠**位置** `[0]`；字典靠**键名** `["role"]` |
| 方括号和点号 | 方括号 = **查表**（列表/字典）；点号 = **进包裹**（对象） |
| 字符串和数字 | `"123"` 是文字，`123` 是数字。`"1" + "2"` = `"12"`，`1 + 2` = `3` |
| 模块和类 | `openai` 是**箱子**（小写）；`OpenAI` 是箱子里的**零件**（大写） |
| `:` 和 `=` | `:` 是"这个键对应这个值"（字典内部）；`=` 是"给这个名字存这个值" |

## 四、一条贯穿全项目的经验

> **崩掉的 bug 是好 bug，静默出错的 bug 才是杀人凶手。**

`api_key` 是 `None` → 第 12 行直接崩，报 `401`。你立刻知道出事了。

但如果它拿到一个**错的值**（比如空的、或者旧的），程序可能一路跑到底，生成一堆垃圾数据，**而你以为一切正常**。

`hello_api.py` 里两类例子都有：
- 删掉 `load_dotenv()` → `None` → **崩**（安全）
- 去掉 `load_dotenv` 的括号 → 静默失效（危险）

**你项目里的 `verify_all.py`（把每条"原文依据"拿回原文逐字比对）就是为了抓第二类问题。** 这是这个项目设计上很聪明的一处。

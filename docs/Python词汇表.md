# Python 词汇表（猴子也能看懂版）

> 用法：看代码遇到不懂的词，来这里查。
> 每条都是"**大白话 + 例子**"，不要求你背，只要求你**看得懂**。
> 顺序：先基础词，后进阶词。

---

## 第 0 层：先搞清"代码"到底是什么

| 词 | 大白话解释 |
|---|---|
| **代码** | 写给电脑看的一串**指令**。电脑会**从上往下一行一行照做**，不会自己跳来跳去（除非你明确让它跳）。 |
| **程序 / 脚本** | 一个 `.py` 文件就是一个程序。叫"脚本"是因为它像剧本，照着演一遍就结束。 |
| **运行 / 执行** | 让电脑真的开始照着做。 |
| **Python** | 一门**语言**（像中文、英文），只是说话的对象是电脑。 |
| **解释器** | 一个**翻译官程序**。你写的 Python 代码它看不懂？不，是**电脑看不懂 Python**，解释器负责把你的话翻译成电脑能执行的动作。你双击运行 `.py`，其实就是解释器在读。 |
| **报错 / 崩溃** | 解释器读到某一行，发现"这话我没法执行"，就**停下来**并把原因打印出来。程序就此中断（除非你写了 `try/except` 接住）。 |

## 第 1 层：最基本的零件

### 1.1 文字、数字、真假

| 词 | 大白话解释 | 例子 |
|---|---|---|
| **字符串** | **一串文字**。必须用引号包起来。英文叫 string，可以理解成"一串字符"。 | `"你好"`、`"001"`、`"a"` |
| **字符** | **一个字**（一个汉字、一个字母、一个标点都算一个字符）。 | `你`、`A`、`，` |
| **整数** | 没有小数点的数字。 | `1`、`120`、`-5` |
| **小数 / 浮点数** | 带小数点的数字。 | `3.14`、`0.3` |
| **布尔值** | **只有两个可能的值：真 或 假**。`True`（真）、`False`（假）。**首字母必须大写**。 | `True`、`False` |
| **None** | Python 里表示"**什么都没有**"的一个特殊值。注意它**不等于 0**，也不等于空字符串——它是"空"。 | `None` |
| **类型** | 这个值是"哪一类东西"。字符串、整数、小数、布尔值，就是四种不同的类型。 | `type("a")` 是字符串类型 |

### 1.2 起名字

| 词 | 大白话解释 |
|---|---|
| **变量** | 一个**贴着名字的盒子**。你把东西放进去，以后喊名字就能拿出来。 |
| **赋值** | "**把右边的结果，装进左边那个名字的盒子里**"。符号是 `=`。**它不是"等于"的意思！** |
| **标识符 / 名字** | 你给盒子起的名字。规则：只能用字母、数字、下划线，**不能以数字开头**，不能有空格。 |
| **关键字** | Python **自己预定了用途的词**，你不能拿它当变量名。例如 `if`、`for`、`def`、`return`、`import`、`None`、`True`。把它们当名字用会报错。 |
| **字面量** | **直接写在代码里的现成值**，不用计算、不用查找。`"你好"`、`5`、`True` 都是字面量。 |
| **常量** | 约定俗成：**全大写名字**表示"这是个配置值，程序运行中不该改它"。这只是**约定**，不是语法规定，你写小写也能跑。 |

### 1.3 容器：装东西的盒子

| 词 | 大白话解释 | 例子 |
|---|---|---|
| **列表（list）** | **一排有先后顺序的格子**，用**方括号** `[]` 包起来，格子和格子之间用**逗号**隔开。取值靠"**第几个**"。 | `["甲", "乙", "丙"]` |
| **字典（dict）** | **一堆"名字: 内容"的配对**，用**大括号** `{}` 包起来。取值靠"**名字**"，不靠顺序。 | `{"姓名": "宝玉", "年龄": 16}` |
| **元组（tuple）** | 和列表几乎一样，也是**一排有顺序的格子**，但用**小括号** `()` 包起来，而且**一旦造好就不能改**（不能增删改）。只用来"放几个固定的东西"。 | `("是", "否")` |
| **元素 / 项** | 容器里**装的每一个东西**。 | `["甲","乙"]` 有两个元素 |
| **索引** | **"第几个"的编号**。⚠️ **Python 从 0 开始数**：第 0 个才是人说的第一个。 | `列表[0]` = 第一个 |
| **键 / 值** | 字典里的"**名字**"叫键（key），"**内容**"叫值（value）。 | `"姓名"` 是键，`"宝玉"` 是值 |
| **嵌套** | **盒子里装盒子**。列表里装字典、字典里装列表，都叫嵌套。 | `[{"甲": 1}, {"甲": 2}]` |
| **空列表** | 一个元素都没有的列表：`[]`。常用来"先准备一个空盒子，等下往里攒东西"。 | `lines = []` |
| **空字符串** | 里面一个字都没有的字符串：`""`。常用来表示"删掉"。 | `"abc".replace("b", "")` |

### 1.4 符号

| 词 | 大白话解释 |
|---|---|
| **注释** | 用 `#` 开头的内容。**从 `#` 到这一行结束，解释器完全无视**，纯粹写给人看。 |
| **缩进** | 行首的**空格**。Python **靠缩进来判断"这几行属于上面哪个东西"**，不是靠好看。缩进错了，程序的意思就变了，甚至直接报错。约定用 **4 个空格**。 |
| **换行符 `\n`** | 一个**看不见的字符**，作用是"这里要换到下一行"。写在字符串里，输出时就真的换行。 |
| **转义符 `\`** | **反斜杠**。它的意思是"**后面这个字符不是它字面的意思，而是有特殊含义**"。比如 `n` 本来只是字母 n，但 `\n` 表示换行。 |
| **原始字符串 `r"..."`** | 字符串前面加个 `r`，意思是"**这里面的 `\` 全部当普通字符，不要当转义符**"。写正则时**必须**加 `r`，否则 `\n`、`\d` 会被误解。 |
| **全角 / 半角** | 中文标点叫全角（`，` `？` `　`），英文标点叫半角（`,` `?` ` `）。它们**是不同的字符**，有时候要专门处理。 |
| **空白字符** | 看不见的字符：空格、换行、制表符。 |

## 第 2 层：让程序做判断和重复

### 2.1 判断

| 词 | 大白话解释 |
|---|---|
| **`if`** | 关键字，意思是"**如果**"。用法：`if 条件:` 然后**缩进**写"条件成立时要做什么"。 |
| **条件** | 一个**能算出"真/假"的式子**。例如 `a == b`、`os.path.exists(路径)`。 |
| **`else`** | "**否则**"。`if` 的条件不成立时，就做 `else` 里的。 |
| **`elif`** | "**否则如果**"（else if 的缩写），用来连着判断好几种情况。 |
| **`==`** | **判断两边是不是相等**，结果是 `True` 或 `False`。⚠️ **和 `=` 完全不同！** `=` 是装进盒子，`==` 是问"一样吗"。 |
| **`!=`** | 判断**不相等**。 |
| **`>` `<` `>=` `<=`** | 大于、小于、大于等于、小于等于。 |
| **`and`** | "**并且**"。两边都真才真。 |
| **`or`** | "**或者**"。有一个真就真。 |
| **`not`** | "**不**"。把真变假、假变真。 |
| **`in`** | "**在……里面**"。`"甲" in ["甲","乙"]` 结果是 `True`。 |
| **非空 / 空** | "空"指 `""`（空字符串）、`[]`（空列表）、`None`。**"非空"就是"里面有东西"**。技巧：`if 某个字符串:` 就是在问"它非空吗"。 |

### 2.2 重复

| 词 | 大白话解释 |
|---|---|
| **`for` 循环** | 关键字，"**挨个走一遍**"。`for x in 一排东西:` 然后缩进写"每拿到一个要怎么处理"。 |
| **`while` 循环** | "**只要条件还成立，就一直重复**"。 |
| **循环体** | `for` / `while` 下面**缩进的那几行**，就是"每轮要反复做的事"。 |
| **迭代 / 遍历** | "**把一排东西挨个拿出来看一遍**"。`for` 干的就是这个。 |
| **`continue`** | 关键字。**跳过这一轮剩下的代码，直接开始下一轮**。（注意：循环没结束，只是这一个不处理了） |
| **`break`** | 关键字。**整个循环立刻结束，跳出去**，后面的也都不做了。 |
| **`range(1, 121)`** | 生成一串数字：1、2、3……120。⚠️ **包前不包后**：写到 121，实际只到 120。 |
| **`len()`** | 数一数**有几个**。`len("你好")` = 2，`len([1,2,3])` = 3。 |
| **无限循环 / 卡死** | 循环永远出不来，或者程序卡在某一步不动了。今天抓取时就卡死过一次。 |

## 第 3 层：造工具和使用工具

| 词 | 大白话解释 |
|---|---|
| **函数** | **你自己造的工具**。造好了，喊一声就能干活。 |
| **`def`** | 关键字，"**我要造一个工具**"。写法：`def 名字(要递进来的东西):` 然后缩进写"这个工具怎么干活"。 |
| **`return`** | 关键字，"**干完活了，把结果交回去**"。⚠️ 它还会**立刻结束这个函数**，后面的代码不执行。 |
| **返回值** | `return` 交回来的那个东西。有返回值的工具，你可以把它存进盒子：`结果 = 工具()`。 |
| **`print`** | 工具，作用是"**把这东西显示到屏幕上**"。⚠️ **它不交回任何东西**（返回 `None`）。 |
| **参数** | 调用工具时**括号里递进去的材料**。 |
| **实参 / 位置参数** | 靠**排队顺序**决定是哪个材料。`load_dotenv("a.txt")`。 |
| **关键字参数** | 靠**名字**决定：`api_key="..."`。好处是顺序可以随便调。 |
| **`()` 括号** | 加在名字后面，意思是"**现在就动手执行**"。不加括号只是"把工具指给你看"，什么都不会发生。 |
| **调用** | "**动手使用**"这个动作。`clean(md)` 就是"调用 clean，把 md 递进去"。 |
| **方法** | **长在某个东西身上的函数**。写法是 `东西.方法()`。例如 `"abc".replace(...)`。 |
| **点号 `.`** | 意思是"**从里面拿出**"。`os.getenv` = 从 os 箱子里拿出 getenv 工具。 |
| **模块** | **一个工具箱**（一个 `.py` 文件）。`os`、`time` 都是模块。 |
| **包** | **装工具箱的箱子**（一个文件夹）。`openai`、`urllib` 都是包。 |
| **`import`** | 关键字，"**把工具箱搬进来**"。`import os` 之后要用 `os.xxx()`。 |
| **`from ... import ...`** | "**只从箱子里掏一个零件出来**"。`from openai import OpenAI` 之后直接写 `OpenAI()`。 |
| **库 / 第三方库** | 别人写好的工具箱。**内置的**（`os`、`time`）装好 Python 就有；**第三方**的（`openai`）要先 `pip install`。 |
| **`pip`** | 装第三方库的工具。 |
| **`requirements.txt`** | 一张清单，写清"这个项目需要装哪些库"。 |

## 第 4 层：类与对象（Python 里最抽象的一组词）

| 词 | 大白话解释 |
|---|---|
| **类（class）** | **一张模具 / 一份"职位的定义"**。它本身**不干活**，只是规定了"造出来的东西会长什么样、能干什么"。约定名字首字母大写，如 `OpenAI`。 |
| **对象（object）** | **按模具造出来的那个具体东西**。它才是真正干活的。 |
| **实例（instance）** | **和"对象"是同一个意思**，只是强调"它是某个类的一个具体个例"。课上说"实例化"就是"造一个出来"。 |
| **实例化** | **造出来的动作**。写法就是"类名后面加括号"：`OpenAI(...)`。 |
| **属性** | **对象身上挂着的数据**。用点号取：`response.usage`。 |
| **父类 / 基类** | **"上一层的模具"**。如果"狗"这个类是从"动物"这个类继承来的，"动物"就是父类。父类的规矩，子类自动都有。 |
| **继承** | 子类**自动拥有**父类的能力，不用重写一遍。 |
| **异常（Exception）** | **程序运行时出的错**的正式叫法。`Exception` 是**所有异常的"总称"**——不管哪种错，都算它的一种。所以写 `except Exception` 能接住几乎所有错误。 |

## 第 4.5 层：包、模块、库、类 —— 一层套一层，怎么认？

**这四个词最容易混。用"从大到小"记：**

```
库（library，口语泛称）
 └─ 包（package）= 一个文件夹
     └─ 模块（module）= 一个 .py 文件
         └─ 类（class）= 文件里的一张"造东西的模具"
```

| 词 | 大白话 | 怎么认出来 |
|---|---|---|
| **库** | **口语，泛指"别人写好的、你拿来用的代码"**。不是严格术语，`urllib`、`openai` 都能叫库。 | 说"这是个库"永远不算错 |
| **包** | **装模块的文件夹** | 通常全是**小写** |
| **模块** | **一个 `.py` 文件** | 通常全是**小写**，可能带点：`urllib.request` |
| **类** | **一张模具**，按它能造出具体的东西 | **首字母大写**：`Request`、`OpenAI` |

**看大小写就能认：**

```python
urllib  .  request  .  Request(url, ...)
└─┬──┘    └──┬───┘    └──┬───┘
  包        模块         类
（小写）   （小写）    （首字母大写 = 模具）
```

**一句话规律**：
- **小写的名字 = 箱子**（包 / 模块），不能拿它干活，只能继续往里点
- **首字母大写的名字 = 模具**（类），**加括号就能造一个具体的出来**

**同一条规律在别处也成立**：`OpenAI` 是类（模具），`openai` 是包。
（回想 `hello_api.py`：`OpenAI(...)` 就是"按模具造一个办事员"。）

## 第 5 层：对付错误

| 词 | 大白话解释 |
|---|---|
| **错误 / 报错** | 程序读到不会执行的地方，**停下来**并打印原因。 |
| **异常** | 同上，正式叫法。 |
| **`try` / `except`** | **`try`** = "试着做下面这些"，**`except`** = "如果出错了，改做这些"。**作用是让程序不崩，能继续往下跑**。 |
| **`as e`** | 把**出错的具体信息**装进名叫 `e` 的盒子，方便你打印出来看。 |
| **抛出异常** | 程序"甩出"一个错误信号。你不接它，程序就崩。 |
| **崩溃 / 中断** | 程序因为没接住的错误而停止。 |
| **静默失败** | ⚠️ **最危险的情况**：程序没报错、正常跑完，但结果是错的。比直接崩溃危险得多。 |

## 第 6 层：文件和路径

| 词 | 大白话解释 |
|---|---|
| **文件路径** | 文件在硬盘上的"地址"。`data/raw/001.txt`。 |
| **`open()`** | 打开一个文件，准备读或写。 |
| **`"r"` / `"w"` / `"a"`** | 打开文件的三种方式。`"r"` = read 读；`"w"` = write 写（**文件原有内容会被清空**）；`"a"` = append 追加（**在末尾接着写，旧内容保留**）。 |
| **读 / 写** | 读 = 把文件内容拿进程序；写 = 把程序里的内容存进文件。 |
| **`with open(...) as f:`** | **打开文件，用完自动关掉**。不用你手动关，就算中途出错也会关。 |
| **`f.read()`** | 把文件**全部内容**读成一个字符串。 |
| **`f.write(内容)`** | 把内容写进文件。 |
| **`flush()`** | "**别攒着了，立刻写进硬盘**"。程序正常结束会自动写，但中途崩了没写的就丢了。 |
| **编码（encoding）** | **"字节"和"文字"之间的翻译规则**。常用 **UTF-8**。⚠️ Windows 上不写 `encoding="utf-8"`，Python 默认用 GBK，**中文会乱码或直接报错**。 |
| **乱码** | 用错编码翻译出来的东西，变成看不懂的符号。 |
| **字节** | 电脑真正存的东西（一串数字）。文字要先"翻译"成字节才能存。 |
| **BOM** | 文件开头隐藏的几个字节，用来标记"我是 UTF-8"。写 CSV 时用 `utf-8-sig` 就是为了让 Excel 认出中文，不然 Excel 打开是乱码。 |
| **私有区字符** | 一段专门留给"自造字"的编码范围。网站上有些字看起来正常，其实是自造字，**复制到别处就变方框**。写 `scan_pua.py` 就是为了抓这种坏字。 |

## 第 7 层：文字处理

| 词 | 大白话解释 |
|---|---|
| **正则表达式（regex）** | **一套用来描述"文字长什么样"的规则**。例如"三个数字"、"以 `<` 开头 `>` 结尾"。用它能**一次找出一批符合模式的文字**，或**批量替换**。写法比较像密码，需要单独学。 |
| **字面匹配** | 正则里**不作特殊解释、就是要一模一样对上**的那部分。正则 `<p>` 里的 `<p>` 就是字面匹配——就必须是这三个字符。 |
| **模式（pattern）** | 你写的那条正则规则本身。 |
| **`re.sub(规则, 换成什么, 在哪儿换)`** | 用正则**批量替换**。`sub` = substitute（替换）。 |
| **`split("分隔符")`** | 按分隔符**把一大段文字切成一个列表**。`"a,b".split(",")` → `["a","b"]`。 |
| **`join(列表)`** | **把列表里的字符串用某个东西连起来**，拼成一大段。`"-".join(["a","b"])` → `"a-b"`。 |
| **`replace("旧的","新的")`** | 把文字里所有的"旧的"换成"新的"。换成 `""` 就是**删掉**。 |
| **`strip()` / `lstrip()` / `rstrip()`** | 去掉**两头**的空白 / 只去**左边** / 只去**右边**。（`l` = left，`r` = right） |
| **`startswith("xx")` / `endswith("xx")`** | 判断是不是**以 xx 开头** / **以 xx 结尾**。 |
| **`count("xx")`** | 数一数 `xx` 出现了几次。 |
| **`append(东西)`** | 往列表**末尾追加**一个东西。 |
| **切片 `[0:3]`** | **取其中一段**。`"abcdef"[0:3]` → `"abc"`。⚠️ **包前不包后**，且**从 0 开始数**。 |
| **格式化字符串** | **把变量塞进文字里**的写法。老式：`"%03d" % num`；新式：`f"{num:03d}"`。 |
| **补零** | 数字位数不够时**在前面填 0**。`1` → `"001"`。这样所有文件名长度一致，排序和切片才不会乱。 |

## 第 8 层：网络与数据交换

| 词 | 大白话解释 |
|---|---|
| **网络请求** | 你的程序**向另一台电脑要东西**。 |
| **URL / 网址** | 要东西的地址。 |
| **服务器** | 存放内容、等着别人来取的电脑。 |
| **客户端** | 主动去要东西的那一方（你这边）。 |
| **下载 / 抓取** | 把网上的内容取回本地存起来。 |
| **`urllib.request`** | Python **自带**的下载工具包。 |
| **`urlopen(url, timeout=30)`** | 打开一个网址取内容。`timeout` = 最多等多少秒。 |
| **`headers` / `User-Agent`** | 附带说明"我是谁"。有些网站会拒绝没有身份的请求。 |
| **`read()`** | 把取回来的**原始字节**读出来。 |
| **`decode("utf-8")`** | 把**字节翻译成文字**。和文件编码是同一件事。 |
| **HTTP 状态码** | 服务器给的回执数字：`200` 成功、`401` 没通过身份验证、`404` 找不到、`429` 请求太频繁。 |
| **超时（timeout）** | "最多等这么久"。超时就报错，不干等。⚠️ 今天遇到的情况证明：**设了 timeout 也可能永久卡死**。 |
| **卡死 / 僵死** | 连接断了但程序不知道，一直等下去。需要用"看门狗"（外部定时杀掉重来）解决。 |
| **API** | **程序之间说话的约定**。你按约定递材料，对方按约定回你东西。 |
| **API Key** | **身份凭证**（一串密码）。代表"这次调用算在谁账上"。 |
| **token（词元）** | 大模型**计费的单位**。不是"字"，大致 1 个 token ≈ 半个到两个汉字。 |
| **JSON** | **一种文本格式的数据**，用来在文件和程序之间搬运"列表和字典"。长得和 Python 的列表、字典几乎一样。`json.load` 读进来，`json.dump` 写出去。 |
| **CSV** | **逗号分隔的表格文本**，Excel 能直接打开。 |

## 第 9 层：环境与工程

| 词 | 大白话解释 |
|---|---|
| **环境变量** | 操作系统给每个程序准备的一小块"**公共便签墙**"。名字自取，值是文字，**程序结束就消失**。 |
| **`.env` 文件** | 一张草稿纸，一行一个 `名字=值`，用来存密钥。**不放代码里，是为了防止泄露**。 |
| **`.gitignore`** | 一张清单，告诉 git "**这些文件不要上传**"。是**安全清单，不是密钥本身**。 |
| **虚拟环境 `.venv`** | 给每个项目**一套独立的库**，互相不干扰。 |
| **依赖** | 你的项目**需要用到的第三方库**。 |
| **`if __name__ == "__main__":`** | 意思是"**只有直接运行这个文件时才执行下面的代码；被别的文件 import 时不要执行**"。用来区分"当程序跑"和"当工具箱被借用"。 |
| **`sys.argv`** | **命令行参数列表**。你敲 `python xx.py 001`，它里面就有 `"001"`。 |
| **命令行参数** | 运行脚本时**跟在文件名后面的额外信息**。 |
| **看门狗（watchdog）** | 一个**外部监督程序**：发现某个任务太久没动静，就杀掉它重新开始。今天抓 120 回就是靠它突破卡死的。 |
| **可复现** | 别人拿到你的代码和数据，**能跑出和你一样的结果**。这是验收的核心要求。 |

## 最容易混的 12 组（老师最爱问）

| 组 | 区别 |
|---|---|
| `=` 和 `==` | `=` 是**装进盒子**；`==` 是**问"一样吗"** |
| `print` 和 `return` | `print` 往屏幕**喊**一声就完；`return` 把结果**交回**给调用处 |
| 加括号和不加括号 | 加括号 = **动手执行**；不加 = 只是把工具指给你看 |
| `continue` 和 `break` | `continue` 跳过**这一个**；`break` **整个循环都不要了** |
| 列表和字典 | 列表靠**第几个**取值；字典靠**名字**取值 |
| 列表和元组 | 列表 `[]` **可以改**；元组 `()` **造好就不能改** |
| 方括号和点号 | 方括号 = **查表**（列表/字典）；点号 = **进包裹**（对象/模块） |
| 位置参数和关键字参数 | 靠**排队顺序** vs 靠**名字** |
| 模块和类 | `openai` 是**箱子**（小写）；`OpenAI` 是箱子里掏出的**零件/模具**（大写） |
| 字符串和数字 | `"123"` 是文字，`123` 是数字。`"1"+"2"` = `"12"`，`1+2` = `3` |
| `"w"` 和 `"a"` | `"w"` **清空重写**；`"a"` **末尾追加** |
| 崩掉 vs 静默失败 | 崩掉会告诉你；**静默失败不报错，但结果是错的**——更危险 |
